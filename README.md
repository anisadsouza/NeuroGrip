# NeuroGrip

Real-time surface-EMG hand-gesture decoding for prosthetic control, running
entirely in the browser.

**Research prototype. Not a medical device. Not validated for clinical use.**

Harsh Bavaskar · Anisa D'Souza · Shruti Shanklesha
BTECH CAP 501, Project Life Cycle Management — ATLAS SkillTech / uGDX

---

## What it does

Reads eight channels of forearm muscle signal, decodes which of ten hand
gestures the wearer intends, and moves the hand *progressively* — starting to
move as evidence accumulates, and committing only when it is sure enough. How
sure it needs to be depends on how hard the mistake would be to undo: closing a
power grip must clear a higher bar than opening a hand.

Everything runs on-device. No signal is uploaded, and none is stored.

## Quick start

```bash
pip install -e "./services/research[dev,ml]"
npm install
npm run dev:web
```

No dataset download and no registration. The signal is generated by a
biophysical motor-unit simulator included in the repository.

[**docs/walkthrough.md**](docs/walkthrough.md) explains the interface and what
every number on it means.

## Where it stands

| | |
| --- | --- |
| Decoder | RBF SVM, 95.6% leave-one-subject-out, ECE 0.022 |
| Latency | 2.2 ms P95 measured, against a 10 ms budget |
| Tests | 248 — 126 Python, 122 TypeScript |
| Built | Simulator, feature pipeline, decoder, evidence accumulation, Live screen |
| Not built | Virtual hand, cartography, error attribution, clinician mode |

**The accuracy figure comes from simulated data** and is optimistic relative to
recorded human sEMG. There is no amputee stratum yet. See
[`docs/model_card.md`](docs/model_card.md) for the full evaluation and its
limitations.

## Layout

| Path | Holds |

| `services/research/` | Python: simulator, features, training, evaluation |

| `docs/` | Walkthrough, model card, design reference, specs and plans |

## Tests

```bash
python -m pytest services/research/tests -q
npm test
npm run typecheck
npm run test:conformance   # proves Python and TypeScript agree on features
```

That last one is the gate that matters: Python trains the model and TypeScript
feeds it at inference, so if the two feature implementations diverge, accuracy
degrades silently with no error anywhere.

[`CLAUDE.md`](CLAUDE.md) has the architecture, the conventions, and the full
command reference.
